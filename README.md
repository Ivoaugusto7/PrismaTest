# TAPN - Sistema Web para Orçamento de Lajes Pré-Moldadas

`CURSO: Sistemas de Informação`

`DISCIPLINA: Trabalho Interdisciplinar Aplicações para Processos de Negócios`

`1º semestre/2026`

Este projeto tem como objetivo propor e desenvolver uma aplicação web voltada para o **dimensionamento de materiais e geração de orçamentos de lajes pré-moldadas**, buscando substituir processos manuais e descentralizados atualmente realizados por meio de planilhas. A solução pretende apoiar a padronização dos cálculos, a centralização das informações e a melhoria do controle dos orçamentos realizados.

Além do desenvolvimento do sistema, o trabalho contempla a **análise do problema real da empresa parceira**, a modelagem de processos de negócio, o levantamento de requisitos, a definição da arquitetura da solução, a prototipação da interface e o planejamento de testes, de forma a garantir uma proposta viável e alinhada às necessidades identificadas.
