# Apresentação do projeto

<span style="color:red">Pré-requisitos: Todos os demais artefatos</span>

Esta seção reúne os materiais de apresentação do projeto **PROLAJE — Sistema Web para Orçamento de Lajes Pré-Moldadas**, desenvolvido para a empresa parceira **Casa Lajes** na disciplina Trabalho Interdisciplinar Aplicações para Processos de Negócios.

## Slides

A apresentação oral da Entrega 2 foi estruturada para demonstrar a evolução da documentação, a validação do protótipo e a proposta técnica da solução.

Os slides devem contemplar os seguintes pontos:

1. Contextualização da empresa parceira e do problema identificado;
2. Modelagem do processo atual (**AS IS**) com os principais gargalos;
3. Modelagem do processo proposto (**TO BE**) com as melhorias previstas;
4. Demonstração do protótipo interativo;
5. Explicação do DER, entidades e relacionamentos;
6. Arquitetura da solução e tecnologias escolhidas;
7. Tabela de rastreabilidade entre requisitos, telas e entidades;
8. Registro do feedback do cliente sobre o protótipo;
9. Próximos passos para a etapa de desenvolvimento.
